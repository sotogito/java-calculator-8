# java-calculator-precourse

지정된 문자와 커스텀 문자를 기준으로 계산되는 문자열 덧셈 계산기

## 주요 비지니스 로직

- 구분자 판별- 기본, 커스텀
- 계산

+ 숫자 추출

## 사용자 시점 플로우

1. 문자열을 입력받는다. `덧셈할 문자열을 입력해 주세요.`
2. 결과가 출력된다. `결과 : 6`

## 애플리케이션 플로우

1. 문자열을 입력받는다. + 유효검증A
3. ""인지 확인 후 바로 0을 반환한다.
4. 커스텀 문자를 지정했는지 확인한다 - 정규식

   #### 일반 계산
    1. 쉼표 또는 콜론을 기준으로 split한다.
    2. List에 숫자를 담는다 + 유효검증D
   #### 커스텀 계산
    1. 유효검증B
    2. 커스텀 문자를 정규식으로 추출한다.
    3. List에 숫자를 담는다 + 유효검증D

6. 숫자가 담긴 리스트를 sum한다.
7. 출력한다.

---

## 유효 검증

- 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료된다.

#### A

- null인가?

#### B

- 문자열의 길이가 1인가? - 길이가 1이 아니면 정규식에 걸리지 않음
- 커스텀 구분자로 숫자를 사용하지 않았는가?
- 커스텀 구분자로 소수점을 사용하지 않았는가?

#### D

- 계산값이 양수인가? - try-catch
- 앞, 뒤 연산자를 사용하지 않았는가?

---

- 결과가 출력되면 프로그램은 종료된다 - 재시작 X
- 기본 구분자와 커스텀 구분자 계산을 구분한다.
- 이스케이프 문자도 커스텀 문자로 사용할 수 있도록 한다. - 미리 로직에서 확인 필요
- 숫자는 커스텀으로 사용 불가하도록 한다.
- 커스텀 구분자는 Length가 1인 문자만 허용한다 - 문자열 X
- 커스텀 구분자는 1개만 설정 가능하다.
- 커스텀 구분자로 .는 사용불가하지만 -는 사용 가능하다.
    - .는 계산시 소수점과 혼동 가능
    - -는 어차피 양수이기 때문에 수식에 사용 불가

# 의문

- 커스텀 구분자를 설정하면 기본 구분자는 어떻게 처리?
    - 커스텀 구분자를 지정했을 경우는 커스텀 구분자로만 계산되도록 구현

- 양수 : 0보다 큰 모든 수
    - 입출력 요구사항에서는 실수를 예시로 두지 않았는데, 입력 조건이 "구분자와 양수로 구성된 문자열"이다. 즉, 실수도 포함한다.
